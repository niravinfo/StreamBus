StreamBus is a modern .NET client for RabbitMQ Streams. You publish plain
objects to a stream by type, consume them with typed handlers, and get
retries and dead-lettering built in.

## Run a local broker

If you don't have RabbitMQ 4.x handy, start one with Docker (streams are
enabled out of the box; the management UI is on `http://localhost:15672`):

```bash
docker run -d --name rabbitmq -p 5552:5552 -p 5672:5672 -p 15672:15672 rabbitmq:4.2-management
```

The `guest` / `guest` credentials work on a local broker.

## The 90% case

Register a host, publish a typed message to a stream, and consume it with
a consumer group. This is a complete program:

```csharp
using Microsoft.Extensions.DependencyInjection;
using Microsoft.Extensions.Hosting;
using Microsoft.Extensions.Logging;
using StreamBus;

var builder = Host.CreateApplicationBuilder(args);

builder.Services.AddStreamBus((_, cfg) =>
{
    cfg.Host("localhost", "/", h => h.Credentials("guest", "guest"));

    cfg.Publish<OrderPlaced>("orders");

    cfg.ReceiveEndpoint("orders", e =>
    {
        e.Consumer<OrderConsumer>("billing");
        e.UseRetry(r => r.Immediate(3));
    });
});

builder.Services.AddStreamBusHosting(h => h.WaitUntilStarted(TimeSpan.FromSeconds(30)));

await builder.Build().RunAsync();

public sealed record OrderPlaced(string OrderId);

public sealed class OrderConsumer(ILogger<OrderConsumer> log) : IConsumer<OrderPlaced>
{
    public Task Consume(ConsumeContext<OrderPlaced> context)
    {
        log.LogInformation("Order {OrderId} at offset {Offset}", context.Message.OrderId, context.Offset);
        return Task.CompletedTask;
    }
}
```

## What happens at startup

- The `orders` stream is declared on the broker if it doesn't exist.
- The `billing` consumer group resumes where it last left off, or reads the
  stream from the first offset on a fresh group; each distinct group name
  gets an independent cursor.
- `AddStreamBusHosting` blocks startup until the broker connection and
  consumers are ready (up to `WaitUntilStarted`), so the service only accepts
  traffic once it can actually process messages.
