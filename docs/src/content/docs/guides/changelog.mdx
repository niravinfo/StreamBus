## Unreleased

- **Breaking:** `Exponential` on the retry configurator is now
  `Exponential(retryCount, minDelay, maxDelay)` — delays double each
  attempt starting at `minDelay`, capped at `maxDelay`. The raw
  `multiplier` parameter is gone; it matched no comparable library.
  Rationale: matches MassTransit/Polly; use `Intervals` for custom growth.
- **Breaking:** `RetryPolicy.Multiplier` is removed; exponential
  growth is fixed at ×2 per attempt, like Polly. For custom growth,
  set `RetryPolicy.DelayCalculator`, or use `Intervals` on the
  fluent configurator.

## 0.2.0

- Bounded retry schedules with exhaustion to a configured destination,
  an owning callback, or the `{stream}_error` classic queue.
- Typed headers on publish and consume.

## 0.1.0

- Initial release: buses, typed publish, consumer-group endpoints,
  global retry with per-endpoint override, explicit fluent
  configuration.
