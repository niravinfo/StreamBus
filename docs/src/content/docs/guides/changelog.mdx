## 0.2.0

- Bounded retry schedules with exhaustion to a configured destination,
  an owning callback, or the `{stream}_error` classic queue.
- Typed headers on publish and consume.
- Replay (streams) and requeue (queues) operations for error-queue
  messages.

## 0.1.0

- Initial release: buses, typed publish, consumer-group endpoints,
  global retry with per-endpoint override, explicit fluent
  configuration.
