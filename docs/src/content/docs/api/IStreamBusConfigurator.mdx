---
title: IStreamBusConfigurator
---

Configures one StreamBus bus: connection, topology, and retry.

```csharp
public interface IStreamBusConfigurator
```

## Methods

### Host

Sets the broker connection; exactly one per bus.

```csharp
Host(string, string, Action<IHostConfigurator>)
```

- [StreamBusConfigurationException](StreamBusConfigurationException) — Called more than once for this bus.

### Publish

Declares a publish stream for TMessage.

```csharp
Publish<T>(string, Action<IStreamOptionsBuilder>)
```

### Publish

Declares a publish stream for TMessage with an explicit declaration spec.

```csharp
Publish<T>(string, StreamOptions)
```

### PublishSuper

Declares a super-stream publish for TMessage.

```csharp
PublishSuper<T>(string, Action<ISuperStreamOptionsBuilder>)
```

### PublishSuper

Declares a super-stream publish for TMessage with an explicit declaration spec.

```csharp
PublishSuper<T>(string, StreamOptions)
```

### ReceiveEndpoint

Declares a receive endpoint on stream for one consumer and consumer group.

```csharp
ReceiveEndpoint(string, Action<IReceiveEndpointConfigurator>)
```

### Serializer

Replaces the message serializer.

```csharp
Serializer(IStreamSerializer)
```

### Serializer

Replaces the message serializer with a System.Text.Json serializer built from a fresh JsonSerializerOptions configured by configure.

```csharp
Serializer(Action<JsonSerializerOptions>)
```

### UseConsumeFilter

Registers a consume filter, discovering its typed message interfaces at runtime. Use IStreamBusConfigurator.UseConsumeFilter&lt;T, T1&gt;() to avoid closing the adapter at runtime. The filter type is registered as a singleton because consume filters are resolved once per bus and cached; register the type as a singleton yourself if you add it before this call.

```csharp
UseConsumeFilter<T>()
```

### UseConsumeFilter

Registers a typed consume filter whose endpoint message type is TMessage. Unlike IStreamBusConfigurator.UseConsumeFilter&lt;T&gt;(), this overload closes the typed adapter at the call site and needs no runtime generic closing. The filter type is registered as a singleton because consume filters are resolved once per bus and cached.

```csharp
UseConsumeFilter<T, T1>()
```

### UseConsumeFilter

Registers a consume filter by type. The type is registered as a singleton because consume filters are resolved once per bus and cached.

```csharp
UseConsumeFilter(Type)
```

### UseConsumeFilter

Registers a consume filter created by factory. The factory runs once per bus; its result is cached for the bus lifetime.

```csharp
UseConsumeFilter(Func<IServiceProvider, IStreamConsumeFilter>)
```

### UseConsumeFilter

Registers an existing consume filter instance, which is used for every delivery on the bus.

```csharp
UseConsumeFilter(IStreamConsumeFilter)
```

### UsePublishFilter

Registers a publish filter, discovering its typed message interfaces at runtime. Use IStreamBusConfigurator.UsePublishFilter&lt;T, T1&gt;() to avoid closing the adapter at runtime. The filter type is registered as a singleton because publish filters are resolved once per bus and cached; register the type as a singleton yourself if you add it before this call.

```csharp
UsePublishFilter<T>()
```

### UsePublishFilter

Registers a typed publish filter whose declared pipe type is TMessage. This overload constructs the typed adapter at the call site and therefore avoids closing a generic type at runtime. It removes one trim/AOT hazard; it does not by itself make trimming or NativeAOT publish supported (the default serializer and type-based configuration are still reflection-based). The filter type is registered as a singleton because publish filters are resolved once per bus and cached.

```csharp
UsePublishFilter<T, T1>()
```

### UsePublishFilter

Registers a publish filter by type. The type is registered as a singleton because publish filters are resolved once per bus and cached.

```csharp
UsePublishFilter(Type)
```

### UsePublishFilter

Registers a publish filter created by factory. The factory runs once per bus; its result is cached for the bus lifetime.

```csharp
UsePublishFilter(Func<IServiceProvider, IStreamPublishFilter>)
```

### UsePublishFilter

Registers an existing publish filter instance, which is used for every publish on the bus.

```csharp
UsePublishFilter(IStreamPublishFilter)
```

### UseRetry

Configures the bus-wide retry schedule; endpoints inherit it unless they override it with their own schedule.

```csharp
UseRetry(Action<IRetryConfigurator>)
```

- [StreamBusConfigurationException](StreamBusConfigurationException) — The callback sets no schedule.

### UseRetry

Sets the bus-wide retry schedule from a raw policy, an escape hatch for schedules the fluent configurator cannot express.

```csharp
UseRetry(RetryPolicy)
```
