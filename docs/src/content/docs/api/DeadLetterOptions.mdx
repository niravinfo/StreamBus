title: DeadLetterOptions
---

Kind-based dead-letter destination. A stream destination sets StreamSpec (queue type unset); a queue destination sets QueueType (stream spec unset). Setting both is unrepresentable by construction — IsStream is QueueType being null.

```csharp
public class DeadLetterOptions
```

## Properties

true when the destination is a stream (no queue type set).
