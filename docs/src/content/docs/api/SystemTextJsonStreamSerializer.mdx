System.Text.Json serializer; ContentType is application/json. Construct with custom JsonSerializerOptions or use Default.

```csharp
public class SystemTextJsonStreamSerializer
```

## Methods

### Deserialize

Deserializes UTF-8 JSON into T; a null result throws JsonException.

```csharp
Deserialize<T>(ReadOnlyMemory<byte>)
```

Serializes message as UTF-8 JSON.

```csharp
Serialize<T>(T)
```
