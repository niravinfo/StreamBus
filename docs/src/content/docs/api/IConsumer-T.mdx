---
title: IConsumer<T>
---

A typed consumer bound to exactly one message type by a receive endpoint. One DI scope is created per delivered message and shared by the pipeline and the consumer constructor.

```csharp
public interface IConsumer<T>
```

## Methods

### Consume

Handles one delivery of T. Throwing triggers the endpoint's retry policy; the offset advances only when the handler succeeds or the failure is handed off.

```csharp
Consume(ConsumeContext<T>)
```
