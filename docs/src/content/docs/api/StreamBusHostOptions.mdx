---
title: StreamBusHostOptions
---

Host-wide start/stop behavior for StreamBus, mirroring MassTransit's BusOptions. Configured through the options pattern; validated by StreamBusHostOptions.ValidateStart(StreamBus.StreamBusHostOptions) / StreamBusHostOptions.ValidateStop(StreamBus.StreamBusHostOptions) before the hosted service uses the values.

```csharp
public class StreamBusHostOptions
```

## Methods

### ValidateStart

Validates the start-phase options: StreamBusHostOptions.StartTimeout must be positive when set. Throws StreamBusConfigurationException otherwise.

```csharp
ValidateStart(StreamBusHostOptions)
```

### ValidateStop

Validates the stop-phase options: StreamBusHostOptions.StopTimeout and StreamBusHostOptions.ConsumerStopTimeout must be positive when set, and StreamBusHostOptions.ConsumerStopTimeout, when set, must not exceed StreamBusHostOptions.StopTimeout (it may be set without it). Throws StreamBusConfigurationException otherwise.

```csharp
ValidateStop(StreamBusHostOptions)
```

## Properties

### ConsumerStopTimeout

Budget for stopping consumers during shutdown; must not exceed StreamBusHostOptions.StopTimeout when both are set, and may be set on its own (default null waits indefinitely).

```csharp
ConsumerStopTimeout
```

### StartTimeout

Overall startup budget when WaitUntilStarted is set; a non-positive value throws StreamBusConfigurationException. Default null waits indefinitely.

```csharp
StartTimeout
```

### StopTimeout

Overall shutdown budget; a non-positive value throws StreamBusConfigurationException. Default null waits indefinitely.

```csharp
StopTimeout
```

### WaitUntilConsumersAttached

When blocking, also block until every typed consumer is attached (or fail when one fails); default true.

```csharp
WaitUntilConsumersAttached
```

### WaitUntilStarted

true when host startup blocks until StreamBus connections and (per WaitUntilConsumersAttached) typed consumers are ready; default false (startup does not block, background failures are logged critically).

```csharp
WaitUntilStarted
```
