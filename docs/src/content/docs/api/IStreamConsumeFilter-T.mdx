---
title: IStreamConsumeFilter<T>
---

Consume filter that runs only on endpoints whose message type is T.

```csharp
public interface IStreamConsumeFilter<T>
```

## Remarks

Filter instances are resolved once when the consumer attaches and cached for the bus lifetime, so a filter must be thread-safe. Register filter types with a singleton lifetime: a scoped or transient registration is rejected when the consumer attaches. Scoped services are available through ConsumeContext.Services.

## Methods

### OnConsume

Runs before the consumer handler. Call next to handle the message, or return without calling it to filter the delivery.

```csharp
OnConsume(ConsumeContext<T>, ConsumeNext)
```
