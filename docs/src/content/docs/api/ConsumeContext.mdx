
Construction is pinned to library code (and test assemblies via InternalsVisibleTo): filters receive and enrich a context built by StreamBus; they never construct their own.

### Services

Per-delivery service scope shared with the typed consumer. Use IServiceProvider.GetService(System.Type) — preferably the GetRequiredService extension — for services the consumer requires. On filterless, untyped endpoints (or a bus built without dependency injection) no scope is created and this provider resolves nothing: it returns null for every type, so treat a null here as "no DI" rather than "service not registered".
