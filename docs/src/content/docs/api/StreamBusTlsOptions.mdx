---
title: StreamBusTlsOptions
---

TLS settings applied to both the stream protocol and AMQP connections.

```csharp
public class StreamBusTlsOptions
```

## Properties

### AcceptableCertificateErrors

Certificate policy errors accepted despite failing validation; default None. Accepting RemoteCertificateNameMismatch or RemoteCertificateNotAvailable disables hostname verification (the TLS protection against man-in-the-middle attacks) and should not be used in production.

```csharp
AcceptableCertificateErrors
```

### ClientCertPassword

Password for the PFX client certificate file; null means no password.

```csharp
ClientCertPassword
```

### ClientCertPath

Path to a PFX client certificate file; null means no client certificate.

```csharp
ClientCertPath
```

### Enabled

Enables TLS for the stream protocol and AMQP connections; false means plain TCP.

```csharp
Enabled
```

### ProtocolVersion

Allowed TLS protocol versions; the default None means the operating system default. Versions below TLS 1.2 (Ssl2, Ssl3, Tls, Tls11) are rejected by validation.

```csharp
ProtocolVersion
```

### ServerName

Server name used for TLS certificate validation (SNI and name matching). When null, connectors fall back to Host at connect time.

```csharp
ServerName
```
