---
title: IStreamSystemHandle
---

Live connection to one broker: the surface the rest of StreamBus uses for producers, consumers, offsets, and topology queries/implementations over a single connected StreamSystem. Dispose closes the system.

```csharp
public interface IStreamSystemHandle
```

## Methods

### CreatePlainProducerAsync

Creates a plain-stream producer.

```csharp
CreatePlainProducerAsync(string, CancellationToken)
```

### CreateRawConsumerAsync

Creates a raw consumer for one stream partition from the given client config.

```csharp
CreateRawConsumerAsync(RawConsumerConfig, CancellationToken)
```

### CreateStreamAsync

Creates a plain stream from a client stream spec (idempotency is the caller's).

```csharp
CreateStreamAsync(StreamSpec, CancellationToken)
```

### CreateSuperStreamAsync

Creates a super stream from a client super-stream spec.

```csharp
CreateSuperStreamAsync(PartitionsSuperStreamSpec, CancellationToken)
```

### CreateSuperStreamProducerAsync

Creates a super-stream producer; every send must carry a routing key.

```csharp
CreateSuperStreamProducerAsync(string, CancellationToken)
```

### QueryPartitionAsync

Lists the partition stream names of a super stream.

```csharp
QueryPartitionAsync(string, CancellationToken)
```

### StoreSystemOffsetAsync

Stores an offset for a consumerGroup on a stream (broker-side persistence).

```csharp
StoreSystemOffsetAsync(string, string, UInt64, CancellationToken)
```

### StreamExistsAsync

true when a plain stream with this name exists.

```csharp
StreamExistsAsync(string, CancellationToken)
```

### SuperStreamExistsAsync

true when a super stream with this name exists.

```csharp
SuperStreamExistsAsync(string, CancellationToken)
```

### TryQueryOffsetAsync

Queries the stored offset for a consumerGroup on a stream without failing when absent.

```csharp
TryQueryOffsetAsync(string, string, CancellationToken)
```

## Properties

### IsClosed

true once the underlying system has been closed or lost.

IsClosed
