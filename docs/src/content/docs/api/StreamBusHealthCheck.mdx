---
title: StreamBusHealthCheck
---

Registers as the streambus health check: healthy only when every registration is attached and every connection ready; degraded while starting/retrying (also when no buses are registered); unhealthy on fatal connections, exhausted declarations, or all typed consumers failed. Data rows are &#123;vhost&#125;|&#123;busType&#125; (connection state) and &#123;vhost&#125;|&#123;registration&#125; (one per consumer/declaration).

