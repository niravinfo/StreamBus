---
title: IStreamPublishFilter
---

Universal publish filter that runs for every typed publish on the bus.

```csharp
public interface IStreamPublishFilter
```

## Remarks

Filter instances are resolved once when the bus is built and cached for the bus lifetime, so a filter must be thread-safe. Register filter types with a singleton lifetime: a scoped or transient registration is rejected when the bus is built. Scoped services are available through Services.

## Methods

### OnPublish

Runs before the publish is serialized and sent.

```csharp
OnPublish(PublishContext, PublishNext)
```
