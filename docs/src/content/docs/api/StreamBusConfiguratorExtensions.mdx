title: StreamBusConfiguratorExtensions
---

AddStreamBus entry points for the service collection.

```csharp
public class StreamBusConfiguratorExtensions
```

## Methods

### AddStreamBus

Adds the default bus (IStreamBus) configured by configure: topology declarations, retry schedules, and receive endpoints are validated and registered immediately.

```csharp
AddStreamBus(IServiceCollection, Action<IStreamRegistrationContext, IStreamBusConfigurator>)
```

- [StreamBusConfigurationException](StreamBusConfigurationException) — The configuration is invalid or contradictory.

### AddStreamBus

Adds a named bus (TBus, exposed as IStreamBus&lt;TBus&gt;) configured by configure: topology declarations, retry schedules, and receive endpoints are validated and registered immediately.

```csharp
AddStreamBus<T>(IServiceCollection, Action<IStreamRegistrationContext, IStreamBusConfigurator>)
```

- [StreamBusConfigurationException](StreamBusConfigurationException) — The configuration is invalid or contradictory.
