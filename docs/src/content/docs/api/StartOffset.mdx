Where a consumer group starts on a partition when no stored offset exists, and how a stored offset is treated.

```csharp
public enum StartOffset
```

## Fields

### AlwaysFirst

Ignore any stored offset and start from the very first offset.

```csharp
AlwaysFirst
```

### AlwaysNext

Ignore any stored offset and start from the next offset after attach.

```csharp
AlwaysNext
```

### ResumeOrFail

Resume from the stored offset; fail attachment when none is stored.

```csharp
ResumeOrFail
```

### ResumeOrFirst

Resume from the stored offset, or the very first offset when none is stored.

```csharp
ResumeOrFirst
```

### ResumeOrNext

Resume from the stored offset, or the next offset after attach when none is stored.

```csharp
ResumeOrNext
```
