---
title: ReadinessPolicy
---

How a publish, consume, or readiness call waits for the connection to become ready. Selectable per call site; only the readiness wait is bounded by this policy — the publish confirm timeout is separate.

```csharp
public class ReadinessPolicy
```

## Methods

### UpTo

Creates a bounded wait policy.

```csharp
UpTo(TimeSpan)
```

### WaitUpTo.constructor

Wait for readiness for at most Timeout, yielding TimedOut when the budget expires.

```csharp
WaitUpTo.constructor(TimeSpan)
```

## Nested types

### FailFast

Do not wait: return immediately, yielding TimedOut when the connection is not already ready.

```csharp
FailFast
```

### WaitIndefinitely

Wait until the connection becomes ready, with no time bound; only cancellation stops the wait.

```csharp
WaitIndefinitely
```
