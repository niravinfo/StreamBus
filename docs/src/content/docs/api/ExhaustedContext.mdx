---
title: ExhaustedContext
---

The failure handed to an OnExhausted callback after the retry schedule is exhausted. Returning from the callback advances past the message; throwing recycles the attach for redelivery.

```csharp
public class ExhaustedContext
```

## Methods

### GetService

Resolves a required service from the exhaustion scope. A missing registration is a runtime DI miss, not invalid bus configuration, so this surfaces the standard InvalidOperationException from ServiceProviderServiceExtensions.GetRequiredService&lt;T&gt;(IServiceProvider).

```csharp
GetService<T>()
```

- InvalidOperationException — No service of type T is registered.
