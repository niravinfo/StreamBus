title: PublishContext

Shared context for one typed publish. Universal and typed publish filters receive the same context instance.

```csharp
public class PublishContext
```

## Methods

### constructor

Construction is pinned to library code (and test assemblies via InternalsVisibleTo): filters receive and enrich a context built by StreamBus; they never construct their own.
