---
title: IStreamBusRegistry
---

Registry that owns one bus (and its connection supervisor) per (bus type, vhost) pair. Buses are created lazily on first request and the same instance is returned for later requests.

```csharp
public interface IStreamBusRegistry
```

## Methods

### DescribeStates

Lists the current connection state of every bus the registry created, for diagnostics and health reporting.

```csharp
DescribeStates()
```

### DisposeAsync

Disposes registry-owned resources; safe to call more than once.

```csharp
DisposeAsync()
```

### ErrorQueuesFor

Gets the AMQP transport shared by error-queue hand-offs on the vhost.

```csharp
ErrorQueuesFor(string)
```

### GetOrCreateBus

Returns the untyped bus for the given vhost, creating it on first use.

```csharp
GetOrCreateBus(string)
```

### GetOrCreateBus

Returns the typed bus for the given vhost, creating it on first use.

```csharp
GetOrCreateBus<T>(string)
```

### GetOrCreateEntry

Gets the cached registry entry for a bus type and vhost, creating it on first use.

```csharp
GetOrCreateEntry(Type, string)
```

### HealthFor

Gets the health aggregator that reports the vhost's connection and consumer states.

```csharp
HealthFor(string)
```

### RemoveSupervisor

Drops the cached supervisor for the vhost so the next request replaces it with a fresh one.

```csharp
RemoveSupervisor(string)
```

### SupervisorFor

Gets the connection supervisor shared by all buses on the vhost.

```csharp
SupervisorFor(string)
```

### TopologyFor

Gets the topology registry that declares streams for the vhost.

```csharp
TopologyFor(string)
```
