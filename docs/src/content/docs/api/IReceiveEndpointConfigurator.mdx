---
title: IReceiveEndpointConfigurator
---

Configures one receive endpoint: consumer, offset, retry, and exhaustion behavior.

```csharp
public interface IReceiveEndpointConfigurator
```

## Methods

### Consumer

Sets the endpoint's typed consumer and its consumer group; exactly once per endpoint. The consumer class must implement IConsumer&lt;T&gt; for exactly one message type.

```csharp
Consumer<T>(string)
```

- [StreamBusConfigurationException](StreamBusConfigurationException) — Called twice, the group name is empty, the group name exceeds the broker's 255-byte limit, or the consumer type implements IConsumer&lt;T&gt; for zero or multiple message types.

### DeadLetterToQueue

Declares a durable AMQP queue dead-letter destination; at most one dead-letter destination per endpoint.

```csharp
DeadLetterToQueue(string, DeadLetterQueueType)
```

- [StreamBusConfigurationException](StreamBusConfigurationException) — A dead-letter destination is already configured, or type is undefined.

### DeadLetterToQueue

Declares a durable AMQP queue dead-letter destination with configured error-queue options; at most one dead-letter destination per endpoint.

```csharp
DeadLetterToQueue(string, DeadLetterQueueType, Action<IErrorQueueOptionsBuilder>)
```

- [StreamBusConfigurationException](StreamBusConfigurationException) — A dead-letter destination is already configured, or type is undefined.

### DeadLetterToStream

Declares a stream dead-letter destination for messages whose retry schedule is exhausted; at most one dead-letter destination per endpoint. The destination is declared at startup with the given spec (partitions are not allowed).

```csharp
DeadLetterToStream(string, Action<IStreamOptionsBuilder>)
```

- [StreamBusConfigurationException](StreamBusConfigurationException) — A dead-letter destination is already configured, or the declaration spec is invalid.

### DeadLetterToStream

Declares a stream dead-letter destination with an explicit declaration spec; at most one dead-letter destination per endpoint.

```csharp
DeadLetterToStream(string, StreamOptions)
```

- [StreamBusConfigurationException](StreamBusConfigurationException) — A dead-letter destination is already configured, or the declaration spec is invalid.

### ErrorPublishTimeout

Sets the timeout for the confirmed publish to the error stream hand-off. Null waits indefinitely; values below one second are raised to one second.

```csharp
ErrorPublishTimeout(Nullable<TimeSpan>)
```

- [StreamBusConfigurationException](StreamBusConfigurationException) — timeout is not positive.

### OnExhausted

Registers a callback that owns the outcome for messages whose retry schedule is exhausted. It shadows a declared dead-letter destination with a startup warning; returning advances past the message, throwing recycles the attach for redelivery. Last call wins.

```csharp
OnExhausted(Func<ExhaustedContext>, Threading.CancellationToken, Threading.Tasks.Task})
```

### UseConsumeFilter

Registers a consume filter on this endpoint and discovers its typed message interfaces at runtime. Use IReceiveEndpointConfigurator.UseConsumeFilter--2 to avoid closing the adapter at runtime. The filter type is registered as a singleton because consume filters are resolved once per bus and cached; register the type as a singleton yourself if you add it before this call.

```csharp
UseConsumeFilter<T>()
```

### UseConsumeFilter

Registers a typed consume filter on this endpoint whose message type is TMessage. This overload constructs the typed adapter at the call site and therefore avoids closing a generic type at runtime. It removes one trim/AOT hazard; it does not by itself make trimming or NativeAOT consume supported (the typed consumer and default serializer are still reflection-based). The filter type is registered as a singleton because consume filters are resolved once per bus and cached.

```csharp
UseConsumeFilter<T, T1>()
```

### UseConsumeFilter

Registers a consume filter on this endpoint by type. The type is registered as a singleton because consume filters are resolved once per bus and cached.

```csharp
UseConsumeFilter(Type)
```

### UseConsumeFilter

Registers a consume filter on this endpoint created by factory. The factory runs once per bus; its result is cached for the bus lifetime.

```csharp
UseConsumeFilter(Func<IServiceProvider>, IStreamConsumeFilter})
```

### UseConsumeFilter

Registers an existing consume filter instance, which is used for every delivery on this endpoint.

```csharp
UseConsumeFilter(IStreamConsumeFilter)
```

### UseRetry

Configures this endpoint's retry schedule, overriding the bus-wide schedule for messages delivered to this endpoint.

```csharp
UseRetry(Action<IRetryConfigurator>)
```

- [StreamBusConfigurationException](StreamBusConfigurationException) — The callback sets no schedule.

### UseRetry

Sets this endpoint's retry schedule from a raw policy, overriding the bus-wide schedule.

```csharp
UseRetry(RetryPolicy)
```
