---
title: IStreamOptionsBuilder
---

Builder for a plain-stream registration spec. No Partitions member: plain streams have no partitions, so the invalid state is not expressible. Setters return void on purpose — no fluent chaining.

```csharp
public interface IStreamOptionsBuilder
```

## Methods

### LeaderLocator

Sets the leader placement rule applied at declare time.

```csharp
LeaderLocator(StreamLeaderLocator)
```

### MaxAge

Sets the retention bound after which older segments are truncated.

```csharp
MaxAge(TimeSpan)
```

### MaxLengthBytes

Sets the total stream size bound in bytes.

```csharp
MaxLengthBytes(UInt64)
```

### MaxSegmentSizeBytes

Sets the size of a single segment file in bytes.

```csharp
MaxSegmentSizeBytes(int)
```
