---
title: PublishContext<T>
---

Typed publish context for a declared message type. It derives from and is the same object as the universal PublishContext.

```csharp
public class PublishContext<T>
```

## Properties

### Message

The published payload as T.

```csharp
Message
```

### TypedPayload

The payload captured as T at construction, so PublishContext-1.Message does not re-cast (and re-unbox for value types) PublishContext.Payload on every access. Falls back to a cast when not set (e.g. contexts constructed in tests).

```csharp
TypedPayload
```
