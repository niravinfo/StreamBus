---
title: RawConsumerCast
---

Fail-fast guard for the StreamSystemHandle.CreateRawConsumerAsync(RawConsumerConfig, CancellationToken) result: the client's StreamSystem.CreateRawConsumer(RawConsumerConfig, ILogger) contract returns IConsumer, but the partition loop requires the concrete RawConsumer subclass (StoreOffset/Close). A client version returning a different concrete type must surface an actionable error here instead of an opaque InvalidCastException from inside the attach loop.

```csharp
public class RawConsumerCast
```

## Methods

### Require

Returns the consumer when it is the required RawConsumer subclass.

```csharp
Require(IConsumer)
```
