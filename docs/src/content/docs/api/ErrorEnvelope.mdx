---
title: ErrorEnvelope
---

The envelope of one failed delivery as it travels to an error destination: the original body plus the failure metadata carried as streambus.error.* application properties, so the destination alone explains what happened. Consuming or draining the destination afterwards is the application's job.

```csharp
public class ErrorEnvelope
```

## Methods

### CaptureUserHeaders

Captures the original user headers of a delivery for the error envelope: framework keys (any streambus.* key, which covers the envelope's own fields), null values (AMQP application properties cannot carry them; a null header is treated as absent), and values a republish could not legally carry (anything but string, bool, int, long) are dropped. Returns null when the delivery carried no user headers.

```csharp
CaptureUserHeaders(IStreamHeaders)
```

### EnvelopeApplicationProperties

Serializes the envelope's own metadata as the flat streambus.error.* application-property map that travels with the failed body.

```csharp
EnvelopeApplicationProperties()
```

### ToApplicationProperties

Flattens the envelope into the application properties for the error-destination publish: the streambus.error.* metadata, with the consume-pipeline SendHeaders and then the original UserHeaders merged on top as plain keys. Envelope fields win key collisions.

```csharp
ToApplicationProperties()
```

### ToHeaders

Flattens the envelope into a header map: the same content as ErrorEnvelope.ToApplicationProperties() minus entries with null values.

```csharp
ToHeaders()
```

### TryParse

Attempts to read an envelope from a delivery that carried the failure metadata as application properties (error-stream hand-off).

```csharp
TryParse(string, Byte[], IReadOnlyDictionary<string, object>, out ErrorEnvelope)
```

### TryParseHeaders

Attempts to read an envelope from a delivery that carried the failure metadata as AMQP message headers (queue hand-off).

```csharp
TryParseHeaders(string, Byte[], IReadOnlyDictionary<string, object>, out ErrorEnvelope)
```
