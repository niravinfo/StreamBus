## Build the app

This is a complete, runnable console app: a bus registration, a
publisher worker, and a consumer — in about 40 lines. Your broker needs
the stream plugin enabled, as described in
[Installation](../installation/).

```csharp
using Microsoft.Extensions.DependencyInjection;
using Microsoft.Extensions.Hosting;
using Microsoft.Extensions.Logging;
using StreamBus;

var builder = Host.CreateApplicationBuilder(args);

builder.Services.AddStreamBus((context, cfg) =>
{
    cfg.Host("localhost", "/", h => h.Credentials("guest", "guest"));

    cfg.Publish<OrderPlaced>("orders");

    cfg.ReceiveEndpoint("orders", e =>
    {
        e.Consumer<OrderConsumer>("billing");
        e.UseRetry(r => r.Immediate(3));
    });
});

builder.Services.AddOptions<StreamBusHostOptions>().Configure(o =>
{
    o.WaitUntilStarted = true;
    o.StartTimeout = TimeSpan.FromSeconds(30);
});

builder.Services.AddHostedService<OrderPublisher>();

await builder.Build().RunAsync();

public sealed record OrderPlaced(string OrderId);

public sealed class OrderConsumer(ILogger<OrderConsumer> log) : IConsumer<OrderPlaced>
{
    public Task Consume(ConsumeContext<OrderPlaced> context)
    {
        log.LogInformation("Order {OrderId} at offset {Offset}", context.Message.OrderId, context.Offset);
        return Task.CompletedTask;
    }
}

public sealed class OrderPublisher(IStreamBus bus, ILogger<OrderPublisher> log)
    : BackgroundService
{
    protected override async Task ExecuteAsync(CancellationToken stoppingToken)
    {
        // Blocking start is configured above, so the bus is already
        // connected when the worker begins.
        while (!stoppingToken.IsCancellationRequested)
        {
            await bus.PublishAsync(new OrderPlaced(OrderId: Guid.NewGuid().ToString("N")), stoppingToken);
            log.LogInformation("Published one order");
            await Task.Delay(TimeSpan.FromSeconds(1), stoppingToken);
        }
    }
}
```

Run it with `dotnet run`. Every second a message travels the whole
path, and the console shows both sides:

```
info: OrderPublisher[0] Published one order
info: OrderConsumer[0] Order ea7b... at offset 0
info: OrderPublisher[0] Published one order
info: OrderConsumer[0] Order 4f2c... at offset 1
```

Stop it with `Ctrl+C`, run it again, and the offsets continue where
the `billing` group left off: the broker stores the group's cursor.

## How the pieces line up

Read the registration the way the library does:

- `cfg.Host("localhost", "/", ...)` — connect to this broker and
  virtual host. Exactly one host per bus.
- `cfg.Publish<OrderPlaced>("orders")` — "messages of type
  `OrderPlaced` live in the stream `orders`", and declare that stream
  at startup if it's missing. That registration is what makes
  publishing possible without naming the stream again.
- `cfg.ReceiveEndpoint("orders", e => ...)` — an endpoint on the same
  stream: a consumer class, a consumer group, and its failure
  behavior. The group (`"billing"`) is the offset cursor identity;
  naming it is required — StreamBus never guesses one for you.
- `e.UseRetry(r => r.Immediate(3))` — if `Consume` throws, retry
  immediately up to three times. Failure handling is
  [a topic of its own](../error-handling/).
- The `AddOptions<StreamBusHostOptions>` block — opt into a blocking
  start: the host waits (up to 30 seconds) until the connection and
  consumer are attached before `RunAsync` finishes starting. The
  default is non-blocking; see [Lifecycle](../lifecycle/).

There is no separate "start the bus" call: `AddStreamBus` registers a
hosted service, so `RunAsync` connects, declares the `orders` stream,
and starts the `billing` consumer. The publisher injects the bus like
any other service.

## What happens at startup

1. The bus connects to the broker (supervised; reconnects on failure).
2. The `orders` stream is declared if it doesn't exist
   ([Topology](../topology/) — including what happens when it exists
   with a different definition).
3. The `billing` consumer group gets a broker-side cursor: it resumes
   where it last left off, or reads the stream from the first offset
   on a fresh group. Each distinct group name is an independent
   cursor.
4. With `WaitUntilStarted = true`, the host waits for all of that —
   bounded by `StartTimeout`.
